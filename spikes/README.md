# Spikes — Dialect

Quick technical experiments to validate assumptions. Each spike is a numbered folder with a README documenting what was tested and what was learned.

## Format

```
spikes/
├── 001-arb-parsing/
│   ├── README.md       # Question, approach, conclusion
│   └── parse.py        # Throwaway code
├── 002-format-conversion/
│   ├── README.md
│   └── convert.ts
└── ...
```

## Spike README Template

```markdown
# Spike NNN: [Title]

## Question
What are we trying to learn?

## Approach
What did we build/test?

## Result
What did we find? Did it work?

## Decision
How does this affect the plan?
```
